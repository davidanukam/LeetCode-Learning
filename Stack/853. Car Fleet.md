## Problem
There are `n` cars traveling to the same destination on a one-lane highway.

You are given two arrays of integers `position` and `speed`, both of length `n`.

- `position[i]` is the position of the `ith car` (in miles)
- `speed[i]` is the speed of the `ith` car (in miles per hour)

The **destination** is at position `target` miles.

A car can **not** pass another car ahead of it. It can only catch up to another car and then drive at the same speed as the car ahead of it.

A **car fleet** is a non-empty set of cars driving at the same position and same speed. A single car is also considered a car fleet.

If a car catches up to a car fleet the moment the fleet reaches the destination, then the car is considered to be part of the fleet.

Return the number of **different car fleets** that will arrive at the destination.

## Example
```python
Input: target = 10, position = [4,1,0,7], speed = [2,2,1,1]

Output: 3
```

## Solution
```python
class Solution:
    def carFleet(self, target: int, position: List[int], speed: List[int]) -> int:
        # 10 - 4 = 6 / 2 = 3
        # 10 - 1 = 9 / 2 = 4.5 -> 5
        # 10 - 0 = 10 / 1 = 10
        # 10 - 7 = 3 / 1 = 3

        cars = []
        for pos, speed in zip(position, speed):
		    cars.append([pos, speed])
        
        cars = list(sorted(cars, reverse=True, key=lambda x: x[0]))
        
        time_stack = []
        for i, car in enumerate(cars):
            time = (target - car[0]) / car[1]
            if len(time_stack):
                if time > time_stack[-1]:
                    time_stack.append(time)
            else:
                time_stack.append(time)
        
        return len(time_stack)
```

First, we want to create a Non-increasing array that sorts each sub array that consists of a car's position and its corresponding speed based on each car's position. We can the cars who are the most ahead to be at the front of our array and the cars who are the most behind to be at the end of the array.

From there, we then create our empty time stack and start looping though our newly created Non-increasing cars array.

To compute the time it takes for any car to reach the target we can use the distance formula (distance = speed * time) and solve for time (time = distance / speed). The distance any given car needs to travel is the difference equal to the target minus the car's starting position. We then divide that distance by the car's speed.
