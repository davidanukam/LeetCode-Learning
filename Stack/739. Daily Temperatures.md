## Problem
You are given an array of integers `temperatures` where `temperatures[i]` represents the daily temperatures on the `ith` day.

Return an array `result` where `result[i]` is the number of days after the `ith` day before a warmer temperature appears on a future day. If there is no day in the future where a warmer temperature will appear for the `ith` day, set `result[i]` to `0` instead.

## Example
```python
Input: temperatures = [30,38,30,36,35,40,28]

Output: [1,4,1,2,1,0,0]
```

## Solution
```python
class Solution:
    def dailyTemperatures(self, temperatures: List[int]) -> List[int]:
        stack = []
        temp_stack = []
        result = [0 for i in range(len(temperatures))]
        for i in range(len(temperatures)):
            while len(stack):
                if temperatures[i] > stack[-1][1]:
                    if i - stack[-1][0] < result[stack[-1][0]] or result[stack[-1][0]] == 0:
                        result[stack[-1][0]] = i - stack[-1][0]
                    temp_stack.append(stack.pop())
                else:
                    break
            stack.append([i, temperatures[i]])
            while len(temp_stack):
                stack.append(temp_stack.pop())
        return result
```

We need to control 3 arrays for this one: Two stacks and one pre-made resulting array.

First we create a resulting array where each element is first set to 0.

We then need to loop through the temperature array and add an array consisting of the current index and the temperature at that index.

Before doing that, however, if our stack is not empty, we can loop through it and check if the current temperature is greater than the last element in the stack. If it is, we can then check if the **current index *minus* the index of the last element** in the stack is either greater than 0 (meaning we have not set a result for that temperature) or less than the value already saved in the resulting index.

Obviously, if it is, then we update the resulting index to equal that new difference.

Regardless, as long as the current temperature is greater than the last element in the stack, we need to remove that last element and store it in the temporary stack.

Then we can, finally, add an array consisting of the current index and the temperature at that index to the stack.

To complete the algorithm, we need to return all the popped out elements from the temporary stack back to the stack (This allows us to create a [Monotonic Decreasing Stack](https://www.geeksforgeeks.org/dsa/introduction-to-monotonic-stack-2/)).

Lastly, we return the resulting array.
