## Problem


## Example
```python
Input: nums = [1,2,3]

Output: [[],[1],[2],[1,2],[3],[1,3],[2,3],[1,2,3]]
```

## Solution
```python
class Solution:
    def subsets(self, nums: List[int]) -> List[List[int]]:
        subsets = [[]]

        for i in range(len(nums)):
            temp_subset = subsets.copy()
            for subset in subsets:
                temp = subset.copy()
                temp.append(nums[i])
                if temp not in temp_subset:
                    temp_subset.append(temp)
            subsets = temp_subset
        
        return subsets
        
```
