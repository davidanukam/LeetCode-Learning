## Problem
Given a string `s`, find the _length of the longest substring_ without duplicate characters.

A **substring** is a contiguous sequence of characters within a string.

## Example
```python
Input: s = "zxyzxyz"

Output: 3
```

## Solution
```python
class Solution:
    def lengthOfLongestSubstring(self, s: str) -> int:
        count = 0
        output = 0
        sub = ""
        for letter in s:
            if len(sub):
                if letter in sub:
	                new_index = sub.index(letter) + 1
                    count -= new_index
                    sub = sub[new_index:]
            sub += letter
            count += 1
            output = max(output, count)
        return output
```

We can setup a count variable and a output variable which will hold the current length of the substring without repeating characters and longest length of the  substring without repeating characters.

We can also have a sub variable be the new string we add and remove letters from as we go through the given string.

Looping through the given string, we can use a sliding window technique and check if out sub string has any characters in it. If it does we then check if the current letter we are on in the given string is found in the sub string.
