## Problem
Given a string `s`, find the _length of the longest substring_ without duplicate characters.

A **substring** is a contiguous sequence of characters within a string.

## Example
```python
Input: s = "zxyzxyz"

Output: 3
```

## Solution
```python
class Solution:
    def lengthOfLongestSubstring(self, s: str) -> int:
        count = 0
        output = 0
        sub = ""
        for letter in s:
            if len(sub):
                if letter in sub:
	                new_index = sub.index(letter) + 1
                    count -= new_index
                    sub = sub[new_index:]
            sub += letter
            count += 1
            output = max(output, count)
        return output
```

We can setup a count variable and a output variable which will hold the current length of the substring without repeating characters and longest length of the  substring without repeating characters.

We can also have a sub variable be the new string we add and remove letters from as we go through the given string.

Looping through the given string, we can use a sliding window technique and check if out sub string has any characters in it. If it does we then check if the current letter we are on in the given string is found in the sub string.

If the current letter is found, then we need to get the first occurrence of it in the sub string. We then add 1 to it and  call this variable the new index.

This new index represents how many letters are to the left of the first occurrence of the found letter in the sub string. Since it is a repeated letter we can subtract it from our count variable (basically removes the letter and all letters to the left of it) and also set our sub string to only include all the letters to the right of the duplicate letter.

Lastly, in the loop, we can add the new letter to the sub string, increment count by 1 and set the output count to be the maximum of the current output count and the current count.
