## Problem
You are given an array of **distinct** integers `nums`, sorted in ascending order, and an integer `target`.

Implement a function to search for `target` within `nums`. If it exists, then return its index, otherwise, return `-1`.

Your solution must run in `O(logn)` time.

## Example
```python
Input: nums = [-1,0,2,4,6,8], target = 4

Output: 3
```

## Solution
```python
class Solution:
    def search(self, nums: List[int], target: int) -> int:
        front = 0
        end = len(nums) - 1
        
        def binary(nums: List[int], target: int, front: int, end: int) -> int:
            if front <= end:
                mid = (front + end) // 2
                if target == nums[mid]:
                    return mid
                if target > nums[mid]:
                    return binary(nums, target, mid + 1, end)
                else:
                    return binary(nums, target, front, mid - 1)
            return -1
        
        return binary(nums, target, front, end)
```

A basic recursive binary search algorithm that takes the front and end of the array as pointers.

Using these pointers, we can check that as long as the front pointer does not pass the end pointer, then we are good to continue.

Within the method, we compute the centre/middle point of out number array using the average formula ((a + b) // 2) making sure to floor it as well (round down to the nearest integer).

We then check if the number located at the index of the middle point is **equal** to our target. If it is, we can return this middle point as the found index.

If our target is **larger** than the number located at the index of the middle point, then we need to search the upper half of the number array. We can do this by calling the method again but with the *front* argument being passed as the `middle point + 1` since we know that the number at the number located at the index of the middle point is not our target.

Otherwise, we know that our target is **smaller** than the number located at the index of the middle point, so we need to search the lower half of the number array. We can do this by calling the method again but with the *end* argument being passed as the `middle point - 1` since we know that the number at the number located at the index of the middle point is not our target.

Eventually, we will either find the number within the array and return the corresponding index, or the front pointer will pass (become greater than) the end pointer and thus returning -1.
