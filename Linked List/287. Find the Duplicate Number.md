## Problem
You are given an array of integers `nums` containing `n + 1` integers. Each integer in `nums` is in the range `[1, n]` inclusive.

There is exactly **one repeated integer** in `nums`, and every other integer appears at most once.

Return the repeated integer.

## Example
```python
Input: nums = [1,2,3,2,2]

Output: 2
```

## Solution 1
```python
class Solution:
    def findDuplicate(self, nums: List[int]) -> int:
        counts = {}

        for num in nums:
            counts[num] = 1 + counts.get(num, 0)
            if counts[num] > 1:
                return num
```

> Note: This is a Pigeon 

We can loop through the entire numbers array and for each number, update its count in our hashmap. 

This way, as soon as we find a number whose count is greater than 1, we can return it.
