## Problem
You are given the head of a singly linked-list.

The positions of a linked list of `length = 7` for example, can initially be represented as:

`[0, 1, 2, 3, 4, 5, 6]`

Reorder the nodes of the linked list to be in the following order:

`[0, 6, 1, 5, 2, 4, 3]`

Notice that in the general case for a list of `length = n` the nodes are reordered to be in the following order:

`[0, n-1, 1, n-2, 2, n-3, ...]`

You may not modify the values in the list's nodes, but instead you must reorder the nodes themselves.

## Example
```python
Input: head = [2,4,6,8]

Output: [2,8,4,6]
```

## Solution
```python
# Definition for singly-linked list.
# class ListNode:
#     def __init__(self, val=0, next=None):
#         self.val = val
#         self.next = next

class Solution:
    def reorderList(self, head: Optional[ListNode]) -> None:
        self.last_node = None

        def get_end(front):
            if front:
                while front.next != None:
                    if front.next == self.last_node:
                        break
                    else:
                        front = front.next
                self.last_node = front
                return self.last_node
            return None
        
        def reorder(front):
            p1 = front
            p2 = get_end(p1)

            if p1 == p2:
                p1.next = None
            elif p1.next == p2:
                p2.next = None
            else:
                p2.next = reorder(p1.next)
                p1.next = p2
            
            return p1

        reorder(head)
```

First, we can make a helper method to get the last *unseen* node in the linked list.

Using a recursive algorithm, we can set a front pointer to point to a node in the linked list. We can then set an end pointer to point to the last unseen node and start a comparison.

If the two pointers point to the same node then we can just return the front pointer.

If the first pointer points to the end pointer then we update the end pointer's next value to be None (as it is now the last node in the reordered linked list).

Otherwise, we can set the next value of the end pointer to be the value returned by calling the reorder function with the next value of the front pointer as an argument.

Then we update the front pointer's next value
