## Problem
Given the `head` of a linked list and an integer `n`, remove the `nth` node from the end of the list and return its head.

## Example
```python
Input: head = [1,2,3,4], n = 2

Output: [1,2,4]
```

## Solution
```python
# Definition for singly-linked list.
# class ListNode:
#     def __init__(self, val=0, next=None):
#         self.val = val
#         self.next = next

class Solution:
    def removeNthFromEnd(self, head: Optional[ListNode], n: int) -> Optional[ListNode]:
        p1 = None
        p2 = head
        p3 = head.next

        # Get the length of the Linked List
        length = 1
        while p2.next != None:
            p2 = p2.next
            length += 1
        
        # Reset pointer
        p2 = head

        index_to_remove = length - n

        curr_index = 0
        while curr_index < length:
            if curr_index == index_to_remove:
                if p1 == None:
					return p3
                else:
                    p1.next = p3
                    break
            else:
                p1 = p2
                p2 = p3
                p3 = p3.next
                curr_index += 1
        
        return head
```

One thing to note is that we know that the given linked list has at least 1 node. Therefore, we can set up this solution using **3 pointers**: A left pointer, a middle pointer and a right pointer.

We can then use our middle pointer to count the number of nodes in the linked list by using a while loop.

Once we have done that, we can reset the middle pointer to point to the head of the linked list.

Now to get the index to remove, we can subtract the given `n` variable from the calculated length.

We can then set up a current index counter and, using a while loop to make sure that the current index is less than the length of the linked list, slide through our linked list to find the node to remove.

To slide through the linked list though, we can first check if the current index is equal to the index to remove. If it is, then we perform two checks. One check is for the edge case (removing the first node) and the other is for every other case (removing a node that is not the first one).

---

Edge Case Explanation:

If the left pointer points to `None` then we need to check two scenarios (but both scenarios are handled the same way).

Scenario 1:
```python
head = [5]
n = 1

p1 = None
p2 = head # 5
p3 = head.next # None
```

In this scenario we are removing the only node in the linked list. So the left pointer points to None and the right pointer also points to None. So we just return the right pointer.

Scenario 2:
```python
head = [5, 1]
n = 2

p1 = None
p2 = head # 5
p3 = head.next # 1
```

In this scenario we are removing the first node in the linked list. So the left pointer points to None **but** the right pointer points to a node. Again, we just return the right pointer.

---

Okay so if we are not in the edge case then all we have to do is make the left pointer's next value point to the right pointer and break out of the while loop (so skipping over the node to remove).

However, if the current index is **not** equal to the index to remove, then we just update our pointers (left pointer now points to middle pointer, middle point now points to right pointer and right pointer now points to its next value) and increment our current index variable.

Outside of the while loop, we just return the head of the linked list.
